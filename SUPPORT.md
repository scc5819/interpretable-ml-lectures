# Support

- **A number in the material looks wrong** → use the
  [content error form](https://github.com/scc5819/interpretable-ml-lectures/issues/new/choose)
  — it asks for the measurement that shows the problem, which is the fastest
  route to a fix.
- **A notebook fails to run or outputs differ** → the
  [reproduction failure form](https://github.com/scc5819/interpretable-ml-lectures/issues/new/choose),
  after checking you are on the pinned stack
  (`pip install --require-hashes -r requirements.lock`, Python 3.14).
- **You want to write a module** → the
  [new module form](https://github.com/scc5819/interpretable-ml-lectures/issues/new/choose);
  the on-ramp is [CONTRIBUTING.md](CONTRIBUTING.md#your-first-contribution).
- **Questions about the course itself** (schedule, enrollment, grading) belong
  with the course staff at ICMC-USP, not in this issue tracker.
- **Conduct concerns** → see the private reporting channel in the
  [Code of Conduct](CODE_OF_CONDUCT.md#enforcement).
