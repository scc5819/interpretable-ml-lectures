# Modules

One module per chapter of Molnar's *Interpretable Machine Learning*, from
chapter 12 onward — **module numbers are Molnar's chapter numbers**, so the
mapping between a lecture and its chapter never drifts. The authoritative list
of chapters, presenters, dates and availability is the
[module board in the root README](../README.md#modules), generated from
[`schedule.toml`](../schedule.toml).

- [`14-lime/`](14-lime/) — LIME (the seed module).
- [`_template/`](_template/) — the starting point for a new module; see
  [Adding a new module](../CONTRIBUTING.md#adding-a-new-module).

Chapters 01–11 are the book's introductory part and out of the course's scope;
chapter 33 (Story Time) is skipped; chapter 34 closes the course as an essay
without a module slot.
